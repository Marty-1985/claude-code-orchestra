A multi-agent collaboration framework that orchestrates Claude Code (1M context), Codex CLI (deep reasoning), and Gemini CLI (external research + multimodal) to accelerate development.

## Key Features

- **Agent Teams** for parallel development with inter-agent communication
- **Skill Pipeline**: `/startproject` → `/team-implement` → `/team-review`
- **Codex CLI** integration for design decisions and debugging
- **Gemini CLI** integration for external research and multimodal processing

## How It Works

Claude Code serves as the orchestrator with its 1M token context window, coordinating specialized agents for different tasks. Agent Teams enable real-time bidirectional communication between teammates.
