# シナリオ設計

## 凡例

- **観点No**: テスト観点一覧の番号に対応
- **シナリオID**: `S-{観点略称}-{連番}`

---

## 1. 表示

| シナリオID | シナリオ名 | 目的 |
|-----------|-----------|------|
| S-DSP-001 | テーブル初期表示 | ページ読み込み時にテーブルが正しく描画される |
| S-DSP-002 | カラムヘッダー表示 | 全9カラム（稼働状況〜編集）が正しい順序・名称で表示される |
| S-DSP-003 | データ行表示 | 各行のセルにデータが正しくマッピングされる |
| S-DSP-004 | データ型別表示 | 日付（最終HTTP通信日時）・数値（電圧抑制回数）・バージョン等が適切な書式で表示される |
| S-DSP-005 | エラー行背景色 | 異常状態の行がピンク背景で表示される |
| S-DSP-006 | エラー件数バッジ | エラー件数がバッジ（青丸数字）で表示される |
| S-DSP-007 | 確定異常/仮異常チェックボックス表示 | テーブル下部に確定異常（赤）・仮異常（黄）のチェックボックスが表示される |
| S-DSP-008 | 更新頻度スライダー表示 | 更新頻度スライダーと選択値が表示される |
| S-DSP-009 | 更新日時表示 | 最終更新日時が表示される |
| S-DSP-010 | フィルタークリアボタン表示 | 「フィルタークリア」ボタンが表示される |
| S-DSP-011 | 件数表示 | 「1-16 of 10016」形式で現在表示範囲と総件数が表示される |
| S-DSP-012 | 編集ボタン表示 | 各行にペンアイコンの編集ボタンが表示される |
| S-DSP-013 | ヘッダーリンク表示 | 「おうち給電TOPへ」リンクとⓘアイコンが表示される |

## 2. 入力

| シナリオID | シナリオ名 | 目的 |
|-----------|-----------|------|
| S-INP-001 | カラム検索（稼働状況） | 稼働状況の検索フィールドで絞り込みができる |
| S-INP-002 | カラム検索（ACC製造番号） | ACC製造番号の検索フィールドで部分一致検索ができる |
| S-INP-003 | カラム検索（PCS製造番号） | PCS製造番号の検索フィールドで絞り込みができる |
| S-INP-004 | カラム検索（ACCバージョン） | ACCバージョンの検索フィールドで絞り込みができる |
| S-INP-005 | カラム検索（最終HTTP通信日時） | 日時での検索が正しく動作する |
| S-INP-006 | カラム検索（電圧抑制回数） | 数値での検索が正しく動作する |
| S-INP-007 | カラム検索（エラー件数） | 数値での検索が正しく動作する |
| S-INP-008 | カラム検索（確認/対応者） | 対応者名での検索が正しく動作する |
| S-INP-009 | 複数カラム同時検索 | 複数カラムの検索条件を組み合わせたAND検索が正しい |
| S-INP-010 | 検索クリア | 検索条件をクリアして全件表示に戻る |
| S-INP-011 | フィルタークリアボタン | 「フィルタークリア」で全検索条件が一括クリアされる |
| S-INP-012 | 特殊文字入力 | 特殊文字（HTML/SQL等）の入力が安全に処理される |
| S-INP-013 | 空白入力 | 空白のみの入力が適切に処理される |
| S-INP-014 | 最大文字数入力 | 長文入力時の動作が正しい |
| S-INP-015 | モーダル：稼働状況ドロップダウン | EditItemモーダルで稼働状況を変更できる |
| S-INP-016 | モーダル：テキストエリア入力 | EditItemモーダルのテキストエリアに入力できる |
| S-INP-017 | モーダル：SAVE操作 | SAVEボタンで変更が保存される |
| S-INP-018 | モーダル：CLOSE操作 | CLOSEボタンで変更を破棄してモーダルが閉じる |

## 3. 遷移

| シナリオID | シナリオ名 | 目的 |
|-----------|-----------|------|
| S-NAV-001 | ページ送り（次へ ＞） | 次ページに遷移してデータが更新される |
| S-NAV-002 | ページ送り（前へ ＜） | 前ページに遷移してデータが更新される |
| S-NAV-003 | 先頭ページへ遷移（\|＜） | 先頭ページへの直接遷移が正しい |
| S-NAV-004 | 末尾ページへ遷移（＞\|） | 末尾ページへの直接遷移が正しい |
| S-NAV-005 | 表示件数切替 | 1ページあたりの件数ドロップダウン（16件）を変更してテーブルが更新される |
| S-NAV-006 | 編集ボタンクリック→モーダル開 | ペンアイコン押下でEditItemモーダルが開く |
| S-NAV-007 | モーダルCLOSE→テーブルに戻る | CLOSEボタンでモーダルが閉じてテーブルに戻る |
| S-NAV-008 | モーダルSAVE→テーブル更新 | SAVE後にモーダルが閉じてテーブルデータが反映される |
| S-NAV-009 | 「おうち給電TOPへ」リンク | ヘッダーリンクでTOPページに遷移する |
| S-NAV-010 | ブラウザバック | ブラウザの戻るボタンで前の状態に復帰する |
| S-NAV-011 | URL直接アクセス | ページ番号等のパラメータ付きURLで直接アクセスした場合の表示が正しい |

## 4. 状態

| シナリオID | シナリオ名 | 目的 |
|-----------|-----------|------|
| S-STA-001 | ローディング表示 | データ取得中にローディングインジケーターが表示される |
| S-STA-002 | 空状態表示（検索結果0件） | 検索条件に該当するデータがない場合のメッセージ表示 |
| S-STA-003 | 自動更新OFF（0分） | 更新頻度0分でデータが自動更新されない |
| S-STA-004 | 自動更新ON | 更新頻度を設定するとデータが自動的にリフレッシュされる |
| S-STA-005 | 確定異常チェックON | 確定異常チェックボックスONで確定異常行がフィルタ表示される |
| S-STA-006 | 仮異常チェックON | 仮異常チェックボックスONで仮異常行がフィルタ表示される |
| S-STA-007 | 確定異常+仮異常チェック同時ON | 両方ONで確定異常+仮異常の行がフィルタ表示される |
| S-STA-008 | チェックボックス全OFF | 両方OFFで通常の全件表示に戻る |
| S-STA-009 | 大量データ表示 | 10016件で正常に表示・操作できる |
| S-STA-010 | 1件のみ表示 | データが1件のみの場合にテーブル・ページングが正しい |
| S-STA-011 | モーダル表示中の背景状態 | モーダル表示中に背景テーブルが操作不可になる |

| S-LST-005 | 検索とページングの連動 | 検索後のページングが検索結果に対して正しく動作する |
| S-LST-006 | 検索とソートの連動 | 検索結果に対してソートが正しく動作する |

| S-LST-008 | チェックボックスフィルタと検索の連動 | チェックボックスと検索の組み合わせが正しい |

## 6. 視認性

| シナリオID | シナリオ名 | 目的 |
|-----------|-----------|------|
| S-VIS-001 | レスポンシブ表示 | 画面幅変更時にテーブルが適切に表示される |
| S-VIS-002 | エラー行のピンク背景 | 異常行がピンク背景で視覚的に区別される |
| S-VIS-003 | エラー件数バッジの視認性 | バッジ（青丸）のサイズ・色がデータ行内で見やすい |
| S-VIS-004 | 確定異常/仮異常チェックボックスの色 | 確定異常が赤、仮異常が黄で区別される |
| S-VIS-005 | ソートインジケーター | 現在のソート方向（↑↓）がカラムヘッダーに表示される |
| S-VIS-006 | モーダルのオーバーレイ | モーダル表示時に背景がグレーアウトされる |

## 7. 操作感

| シナリオID | シナリオ名 | 目的 |
|-----------|-----------|------|
| S-UX-001 | 検索レスポンス | 検索入力後、結果が体感で遅延なく表示される |
| S-UX-002 | ページ切替レスポンス | ページ切替操作後、すぐにデータが表示される |
| S-UX-003 | デバウンス動作 | 連続入力時に過剰なAPI呼び出しが発生しない |
| S-UX-004 | 連続操作耐性 | ページングボタンの連打でエラーにならない |
| S-UX-005 | モーダル開閉レスポンス | 編集ボタン押下→モーダル表示が即座に行われる |
| S-UX-006 | 自動更新のスムーズさ | 自動更新時にちらつきや画面ジャンプがない |
| S-UX-007 | 更新頻度スライダー操作性 | スライダーがスムーズに操作でき、選択値が即座に反映される |

| S-ERR-005 | 不正ページ番号 | 存在しないページ番号指定時の動作が正しい |

| S-ERR-008 | 自動更新中のエラー | 自動更新時にAPIエラーが発生した場合の動作が正しい |
