# シナリオ設計

## 凡例

- **観点No**: テスト観点一覧の番号に対応
- **シナリオID**: `S-{観点略称}-{連番}`

---

## 1. 表示

| シナリオID | シナリオ名 | 目的 |
|-----------|-----------|------|
| S-DSP-001 | テーブル初期表示 | ページ読み込み時にテーブルが正しく描画される |
| S-DSP-002 | カラムヘッダー表示 | 全カラムのヘッダーが正しい順序・名称で表示される |
| S-DSP-003 | データ行表示 | 各行のセルにデータが正しくマッピングされる |
| S-DSP-004 | データ型別表示 | 日付・数値・ステータス等が適切な書式で表示される |
| S-DSP-005 | 長文テキスト表示 | セル内の長文がトランケートまたはツールチップで処理される |

## 2. 入力

| シナリオID | シナリオ名 | 目的 |
|-----------|-----------|------|
| S-INP-001 | テキスト検索 | カラム検索フィールドにテキストを入力して絞り込みができる |
| S-INP-002 | 部分一致検索 | 部分文字列での検索結果が正しい |
| S-INP-003 | 複数カラム検索 | 複数カラムの検索条件を組み合わせて絞り込みができる |
| S-INP-004 | 検索クリア | 検索条件をクリアして全件表示に戻る |
| S-INP-005 | 特殊文字入力 | 特殊文字（記号・絵文字・SQLインジェクション文字列等）の入力が安全に処理される |
| S-INP-006 | 空白入力 | 空白のみの入力が適切に処理される |
| S-INP-007 | 最大文字数入力 | 入力文字数上限を超えた場合の動作が正しい |

## 3. 遷移

| シナリオID | シナリオ名 | 目的 |
|-----------|-----------|------|
| S-NAV-001 | ページ送り（次へ） | 次ページに遷移してデータが更新される |
| S-NAV-002 | ページ送り（前へ） | 前ページに遷移してデータが更新される |
| S-NAV-003 | 先頭ページへ遷移 | 先頭ページへの直接遷移が正しい |
| S-NAV-004 | 末尾ページへ遷移 | 末尾ページへの直接遷移が正しい |
| S-NAV-005 | ページ番号直接指定 | 任意のページ番号を指定して遷移できる |
| S-NAV-006 | 表示件数切替 | 1ページあたりの表示件数を変更してテーブルが更新される |
| S-NAV-007 | 行クリック遷移 | テーブル行クリックで詳細ページに遷移する |
| S-NAV-008 | ブラウザバック | ブラウザの戻るボタンで前の状態に復帰する |
| S-NAV-009 | URL直接アクセス | ページ番号付きURLで直接アクセスした場合の表示が正しい |

## 4. 状態

| シナリオID | シナリオ名 | 目的 |
|-----------|-----------|------|
| S-STA-001 | ローディング表示 | データ取得中にローディングインジケーターが表示される |
| S-STA-002 | 空状態表示 | データが0件の場合に適切なメッセージが表示される |
| S-STA-003 | 検索結果0件 | 検索条件に該当するデータがない場合のメッセージ表示 |
| S-STA-004 | 大量データ表示 | 大量データ（1000件以上）で正常に表示・動作する |
| S-STA-005 | 1件のみ表示 | データが1件のみの場合にテーブル・ページングが正しい |

## 5. 一覧

| シナリオID | シナリオ名 | 目的 |
|-----------|-----------|------|
| S-LST-001 | デフォルトソート | 初期表示時のソート順が仕様通りである |
| S-LST-002 | カラムソート昇順 | カラムヘッダークリックで昇順ソートされる |
| S-LST-003 | カラムソート降順 | 再クリックで降順ソートに切り替わる |
| S-LST-004 | ソートとページングの連動 | ソート変更後もページングが正しく動作する |
| S-LST-005 | 検索とページングの連動 | 検索後のページングが検索結果に対して正しく動作する |
| S-LST-006 | 検索とソートの連動 | 検索結果に対してソートが正しく動作する |
| S-LST-007 | 件数表示の正確性 | 「全X件中 Y-Z件を表示」の数値が正確である |

## 6. 視認性

| シナリオID | シナリオ名 | 目的 |
|-----------|-----------|------|
| S-VIS-001 | レスポンシブ表示 | 画面幅変更時にテーブルが適切にリサイズされる |
| S-VIS-002 | ハイライト表示 | 検索キーワードのハイライトまたは該当行の強調表示 |
| S-VIS-003 | 現在ページハイライト | ページネーションで現在ページが視覚的に区別される |
| S-VIS-004 | ステータス色分け | ステータスカラムの値に応じた色分け表示 |
| S-VIS-005 | テーブルストライプ | 行の交互色分けで視認性が確保されている |

## 7. 操作感

| シナリオID | シナリオ名 | 目的 |
|-----------|-----------|------|
| S-UX-001 | 検索レスポンス | 検索入力後、結果が体感で遅延なく表示される |
| S-UX-002 | ページ切替レスポンス | ページ切替操作後、すぐにデータが表示される |
| S-UX-003 | デバウンス動作 | 連続入力時に過剰なAPI呼び出しが発生しない |
| S-UX-004 | 連続操作耐性 | ページングボタンの連打でエラーにならない |
| S-UX-005 | 操作フィードバック | ボタン押下時にホバー・アクティブ状態が視認できる |

## 8. アクセシビリティ

| シナリオID | シナリオ名 | 目的 |
|-----------|-----------|------|
| S-A11Y-001 | キーボード操作 | Tab/Enter/矢印キーでテーブル・ページング操作が可能 |
| S-A11Y-002 | スクリーンリーダー | テーブル構造がaria属性で正しく伝わる |
| S-A11Y-003 | フォーカス表示 | フォーカス中の要素が視覚的に識別できる |
| S-A11Y-004 | コントラスト比 | テキストと背景のコントラスト比がWCAG AA基準を満たす |

## 9. 権限

| シナリオID | シナリオ名 | 目的 |
|-----------|-----------|------|
| S-AUTH-001 | 閲覧可ユーザーアクセス | 閲覧権限があるユーザーでテーブルが正しく表示される |
| S-AUTH-002 | 閲覧不可ユーザーアクセス | 閲覧権限がないユーザーでアクセス拒否される |
| S-AUTH-003 | 未ログインアクセス | 未ログイン状態でアクセスした場合にログインへリダイレクトされる |
| S-AUTH-004 | セッション切れ | 操作中にセッションが切れた場合の遷移が正しい |

## 10. ファイル

| シナリオID | シナリオ名 | 目的 |
|-----------|-----------|------|
| S-FILE-001 | CSV エクスポート | テーブルデータをCSVでダウンロードできる |
| S-FILE-002 | 検索結果エクスポート | 検索で絞り込んだ結果のみエクスポートされる |
| S-FILE-003 | 大量データエクスポート | 大量データのエクスポートがタイムアウトしない |
| S-FILE-004 | ファイル名規則 | ダウンロードファイル名が命名規則に従っている |

## 11. 例外

| シナリオID | シナリオ名 | 目的 |
|-----------|-----------|------|
| S-ERR-001 | API エラー（500） | サーバーエラー時にエラーメッセージが表示される |
| S-ERR-002 | ネットワークエラー | 通信断時に適切なエラー表示がされる |
| S-ERR-003 | タイムアウト | API応答遅延時にタイムアウト処理が動作する |
| S-ERR-004 | 不正ページ番号 | 存在しないページ番号指定時の動作が正しい |
| S-ERR-005 | 同時操作 | 複数タブで同時操作した場合にデータ不整合が起きない |
| S-ERR-006 | データ不整合 | 表示中にデータが更新された場合の動作が正しい |
