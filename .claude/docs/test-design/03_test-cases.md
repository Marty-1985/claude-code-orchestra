- **テストケースID**: `TC-{シナリオID}-{連番}`
- **優先度**: P1（必須）/ P2（重要）/ P3（推奨）
- **自動化**: A（自動化対象）/ M（手動確認）

エクセル転記時はタブ区切りでコピー可能。
