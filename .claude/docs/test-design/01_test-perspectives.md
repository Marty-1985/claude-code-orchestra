# テスト観点一覧

## 対象ページ

機器情報一覧ページ（テーブル表示・カラム検索・ページング）

## 前提

| 項目 | 内容 |
|------|------|
| フレームワーク | Playwright |
| 権限モデル | 閲覧可 / 閲覧不可 |
| カラム構成 | 汎用（ID, 名前, ステータス, 場所, 登録日 等） |

## テスト観点

| No | 観点 | 概要 | 優先度 |
|----|------|------|--------|
| 1 | 表示 | テーブル・カラム・データが正しく描画されること | 高 |
| 2 | 入力 | 検索フィールドへの入力が正しく処理されること | 高 |
| 3 | 遷移 | ページング・リンク等の画面遷移が正しいこと | 高 |
| 4 | 状態 | データ件数・ローディング・空状態の表示が正しいこと | 高 |
| 5 | 一覧 | ソート・フィルタ・データ整合性が正しいこと | 高 |
| 6 | 視認性 | テキスト・レイアウトが見やすいこと | 中 |
| 7 | 操作感 | レスポンス速度・フィードバックが適切なこと | 中 |
| 8 | アクセシビリティ | スクリーンリーダー・キーボード操作が可能なこと | 中 |
| 9 | 権限 | 閲覧可/不可で表示制御が正しいこと | 高 |
| 10 | ファイル | エクスポート・ダウンロード機能が正しいこと | 低 |
| 11 | 例外 | エラー・タイムアウト時の表示が正しいこと | 高 |
